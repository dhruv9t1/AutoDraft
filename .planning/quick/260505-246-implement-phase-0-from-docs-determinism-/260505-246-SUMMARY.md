# Quick Task 260505-246: Phase 0 Determinism Lockdown Summary

## What Was Implemented

Sampling lockdown + JSON schema output + determinism tests for the Rust backend as specified in `docs/DETERMINISM_AND_ACCURACY_TRACK.md` lines 34-47.

**Task 1 — Sampling lockdown + JSON schema + Config wiring (commit 996423f):**

- `OllamaChatRequest` extended with five new optional fields, each with `#[serde(skip_serializing_if = "Option::is_none")]`: `temperature`, `top_p`, `top_k`, `seed`, `format`
- `variables_response_schema()` function returns a full JSON schema for `{variables: [{variableName, originalText, position, confidenceScore}]}` with camelCase wire names matching existing serde rename attributes
- Request construction site now populates all four sampling fields from `Config` and sets `format: Some(variables_response_schema())`; `response_format` is retained alongside for the OpenAI-compat transition
- `Config` extended with `ollama_temperature: f64` (default 0.0), `ollama_top_p: f64` (default 1.0), `ollama_top_k: u32` (default 1), `ollama_seed: u64` (default 42) — all env-overridable
- `chunk_document_for_test` public wrapper added to `OllamaService` for integration test access without changing the private `chunk_document` method
- `backend/.env.example` created (NEW file — `.env` not touched) documenting all env vars with the four new determinism vars flagged with a DO NOT CHANGE comment

**Task 2 — Determinism tests + fixture + lib crate target (commit 32a76dd):**

- `[lib]` target added to `backend/Cargo.toml` with name `word_addin_backend`, path `src/lib.rs`
- `backend/src/lib.rs` created with minimal surface: `pub mod config; pub mod models; pub mod ollama;` (handlers excluded — depends on `AppState` in main.rs)

- `backend/tests/chunking_determinism.rs`: 2 CI-safe unit tests, no network calls — `chunker_is_deterministic_across_runs` and `chunker_boundaries_stable`; both pass
- `backend/tests/determinism_snapshot.rs`: 1 `#[tokio::test] #[ignore]` test, dual-gated (ignore + OLLAMA_DETERMINISM_TEST=1 env var); shows `0 passed; 0 failed; 1 ignored` in default `cargo test`
